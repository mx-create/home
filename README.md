# home

Index page for mxdesign.uk that links out to every site: Julix DJ, the Julix&Mx label, MX Design Studio, the blog and Cardshare (cardshare.io).

Plain static HTML, no build step. Deploy with Hostinger hPanel's Git tool (Advanced → GIT) pointed at this repo and the `public_html` folder for mxdesign.uk.

To add or change a site, edit its `<li>` tile in `index.html`. Logos are in `images/`.
