Rows are tinted by type:raillogicdataclock. Data rows draw as a bus that turns valid once up; clock rows toggle while up. Click the ⠿ handle to select a row (Shift+click for several), then Ctrl+C / Ctrl+V to copy it in below. Drag the handle to move rows.

Keyboard shortcuts and input formats
  • Ctrl+C in a cell with nothing highlighted copies the whole row; Ctrl+V in any cell then inserts it below that row with a new name (3V3 → 3V3_2).
  • With rows selected: Ctrl+C copy, Ctrl+X cut, Ctrl+V insert below, Delete remove, ↑ ↓ move, Esc back to editing.
  • Ctrl+D or ⧉ duplicates the current row.
  • Ctrl+Z undo, Ctrl+Y or Ctrl+Shift+Z redo. Deleting and pasting can always be undone.
  • ↑ ↓ or Enter move between rows in the same column; Enter on the last row adds a new one. Esc in a cell selects its row.
  • Alt+↑ / Alt+↓ in a cell moves the row.
  • Pasting a block copied from Excel into a cell fills from that cell and adds rows as needed.
  • “Start after” / “Stop after” open a list with the rows just above and below first. VCCINT waits for VCCINT to cross the PG threshold; VCCINT.start waits only for it to begin ramping. In “Stop after”, a name waits for that signal to fall below the off threshold.
  • Times accept ms, us or s; levels accept 3V3.
